# August Rakvaag webpage
## Purpose
My Github pages is a collection of personal html/js projects. They mostly stem from needing a really niche tool that doesn't exist anywhere else.

## Projects
### Interval program
The interval program was created to use when holding spinning classes. It gives the attendants something motivating to look at, while also reducing the work for the instructor. It works by reading a JSON description of the session, and creating a series of countdowns.

### Hove countdown
This is just a simple countdown to a hardcoded UNIX timestamp. Counts both seconds and days.

### Poker payments
This tool solves the issue of who should pay who at the end of a poker cash game without having to go through a central node.
